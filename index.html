Nova Backup

A personal, owner-operated tool for encrypted backups to Google Drive.

Purpose

Nova Backup uses rclone and Restic to back up server configuration and selected application data to a dedicated repository in the owner's Google Drive. It supports integrity checks and recovery.

Google Drive access

The owner authorizes a Google account using a Desktop OAuth client. The requested permission is https://www.googleapis.com/auth/drive.file, which limits access to files created or explicitly opened with this application. Nova Backup uses this permission to manage its own encrypted backup files and folders.

Data handling

Backup contents are encrypted with Restic before upload. Credentials are kept in restricted storage on the owner's devices. Backup retention is controlled by the owner.

Read the privacy policy for details about access, storage, deletion and hosting.

Contact

This application is used by its owner. Questions about these information pages can be directed to the project contact. Do not include passwords, tokens or recovery keys in public messages.
