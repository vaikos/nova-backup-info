Privacy policy

Nova Backup is a personal backup application operated for its owner's Google account.

Information accessed and purpose

The application requests the Google Drive drive.file permission to create, list, read, update and delete the backup repository's files and folders. Google may also provide account or storage-quota metadata needed for the authorized connection and storage monitoring. This information is used for backup, integrity verification, retention and recovery.

Storage and protection

Selected server configuration and application data are encrypted with Restic before they are uploaded to Google Drive. Processing takes place on the owner's Windows and server environments. OAuth credentials are stored with restricted access on the owner's devices. The recovery password is kept separately by the owner, with a protected operational copy on the server.

Use and sharing

Google API data is used to deliver this backup and recovery service. It is not sold, used for advertising, or used to train general-purpose AI models. Human access is limited to the owner and maintenance or security access authorized by the owner. Backup objects are transferred to Google Drive as part of the service requested by the owner.

Use of Google API information follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

The owner controls retention settings. Expired snapshots and unreferenced encrypted blocks may be deleted from the dedicated repository. The owner can delete repository data in Google Drive and revoke the application's authorization through Google Account connections. Revoking authorization does not automatically delete files already stored in Drive.

Information-page hosting

These static information pages contain no analytics code or advertising. GitHub Pages hosts the pages and logs visitor IP addresses for security under the GitHub Privacy Statement. Google's handling of data on its services is described in the Google Privacy Policy.

Contact and changes

The support address is displayed on the application's Google consent screen. Questions about these pages can also be sent to the project contact. Do not put credentials or recovery passwords in public messages.

This policy will be updated before the application changes how it uses Google data. The owner must authorize any new permissions.
